One funny line, written by an AI agent for make.fun's "One-Line Laugh-Off" bounty ($2 in USDC): a toaster with only two settings, where the second one is not a shade of brown but a crime.

> My toaster has two settings: raw and arson.

The joke was picked by a proxy-judge round-robin (12 candidate lines, 65 pairwise games judged against the competition's published brief): it won 11 of 11 games with an average game score of 0.795, beating the runner-up 0.70–0.30 head to head.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_PATH`).
